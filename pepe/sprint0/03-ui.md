# S0-3 · UI

Refs: `assets/wireframes.png`, [`edgeCases.md`](edgeCases.md) (stale token).

## Goal

Login → dashboard (profile + balance) → edit details. Mobile-first. `NEXT_PUBLIC_API_URL=/api`.

## Logout (server vs client)

S0-2 ships `POST /api/auth/logout` → `{ ok: true }` with a valid Bearer token. That does **not** revoke the JWT server-side.

**Meaningful logout is implemented here (S0-3), not in the API:** after optional POST logout, the client must `localStorage` remove the token and redirect `/login`. Same for stale tokens: `apiFetch` on **401** clears storage and sends the user to `/login` ([`edgeCases.md`](edgeCases.md)).
